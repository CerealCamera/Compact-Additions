### Overview:

Create: Inverted Analog Transmission adds an inverted analog transmission to Create: Simulated.

### Usage:

The inverted analog transmission is a neat and simple way to control RPM with analog redstone signal. It's especially useful for controlling a vehicle and its speed from a single input source, such as a tweaked controller.

### Technical:

The inverted analog transmission behaves just like the standard analog transmission, but with its signal flipped.
